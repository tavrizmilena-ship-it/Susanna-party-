# Подключение анкеты к Google Таблице (для личного аккаунта Gmail)

Power Automate не работает с личными аккаунтами Microsoft (ошибка `AADSTS500200`).
Для Gmail используется Google Таблица: она бесплатная, а её можно в любой момент скачать
как файл Excel: **Файл → Скачать → Microsoft Excel (.xlsx)**.

```
Телефон гостя → сайт /api/rsvp (Vercel, проверка, секрет) → Google Apps Script → Google Таблица
```

Секретное слово и адрес скрипта хранятся только на сервере Vercel, гости их не видят.

## 1. Создайте таблицу
1. Откройте https://sheets.google.com под вашим Gmail.
2. Нажмите **Пустой файл** и назовите таблицу `Susanna RSVP`.

## 2. Вставьте скрипт
1. В таблице откройте **Расширения → Apps Script**.
2. Удалите всё, что есть в редакторе, и вставьте целиком код из файла
   `scripts/google-apps-script.gs`.
3. В строке `const SECRET = 'ВСТАВЬТЕ_СЮДА_СЕКРЕТНОЕ_СЛОВО';` замените текст в кавычках
   на своё секретное слово: длинное, без пробелов, например `Rozovye-piony-4-noyabrya-7Kq2xW9mZ`.
4. Нажмите на значок дискеты (**Сохранить**).

## 3. Создайте листы
1. Вверху, в списке функций, выберите **setup** и нажмите **Выполнить**.
2. Google попросит разрешение. Нажмите **Проверить разрешения**, выберите свой аккаунт,
   затем **Дополнительные настройки → Перейти на страницу «…» (небезопасно)** и **Разрешить**.
   Это ваш собственный скрипт, предупреждение стандартное.
3. Вернитесь в таблицу. Появятся листы **RSVP Responses**, **Summary** и **Invited**.

## 4. Опубликуйте скрипт как веб-приложение
1. В Apps Script нажмите **Начать развёртывание → Новое развёртывание**.
2. Нажмите на шестерёнку рядом с «Выберите тип» и выберите **Веб-приложение**.
3. Заполните:
   - **Выполнять от имени:** «Я (ваш gmail)»;
   - **У кого есть доступ:** «Все».
4. Нажмите **Начать развёртывание** и скопируйте **URL веб-приложения**.
   Он заканчивается на `/exec`.

Если позже вы поменяете код скрипта, нажмите **Начать развёртывание → Управление
развёртываниями**, затем значок карандаша, выберите **Версия: новая** и нажмите
**Начать развёртывание**. Адрес при этом не изменится.

## 5. Подключите к сайту в Vercel
Откройте **Settings → Environment Variables** и добавьте переменные для окружения *Production*:

| Name | Value |
|---|---|
| `EXCEL_DRIVER` | `google-sheets` |
| `GOOGLE_SCRIPT_URL` | URL веб-приложения из шага 4 |
| `RSVP_SHARED_SECRET` | то же секретное слово, что в скрипте |

Затем откройте **Deployments**, у верхней публикации нажмите **⋯ → Redeploy**.

## 6. Проверьте
1. Отправьте на сайте анкету с именем «Тест Тестов».
2. В таблице на листе **RSVP Responses** появится строка, на листе **Summary** изменятся числа.
3. Удалите тестовую строку.

Если вместо «Спасибо» появилась ошибка, проверьте в Vercel → **Logs**. Ответ `unauthorized`
означает, что секретное слово в скрипте и в Vercel не совпадает.

## 7. Доступ для Susánna
В таблице нажмите **Настройки доступа**, добавьте её почту с правом **Редактор**.
Общий доступ по ссылке не включайте.
