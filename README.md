# Susánna’s birthday party — сайт-приглашение

Мобильный сайт-приглашение: обложка с фотографией и числом 20, дата и время, дресс-код,
адрес с кнопкой карты, анкета гостя и подпись автора. Ответы анкеты записываются в Excel.

**Стек:** React 18, TypeScript, Vite и обычный CSS. Библиотек анимации нет: параллакс и
появление блоков сделаны на `requestAnimationFrame` и `IntersectionObserver`
(`src/lib/motion.ts`). Сервер — одна функция Vercel `api/rsvp.ts`, секреты хранятся
только в ней.

**Графика:** только оригинальные изображения заказчицы — гирлянда пионов и пион на стебле
(`assets-src/`). Они используются целиком, без нарезки: гирлянда — вверху обложки и в конце
страницы, пион на стебле лежит горизонтально у фото, между секциями и на уголке анкеты
(цветок виден полностью, стебель уходит за край экрана). Скрипт `scripts/prepare-art.py`
переводит белую заливку в прозрачность и сохраняет WebP в нескольких размерах.

**Вес страницы на телефоне:** JS около 53 КБ (gzip), фото 46 КБ, гирлянда 96–219 КБ,
пион на стебле 120 КБ (подгружается по мере прокрутки).

## Структура

```
src/config.ts                  ВСЕ тексты, дата, время, адрес, палитра, ссылки
src/components/Sections.tsx    Обложка, Дата и время, Дресс-код, Место, Колофон
src/components/Rsvp.tsx        Анкета
src/lib/motion.ts              Параллакс и появление секций
src/styles.css                 Дизайн-система: цвета, шрифты, сетка, анимации
api/rsvp.ts, api/_lib/         Серверная проверка анкеты и запись в Excel
assets-src/                    Оригинальные цветочные изображения
public/art/*.webp              Подготовленные изображения (scripts/prepare-art.py)
public/img/*.webp              Фото без фона
public/og.jpg                  Превью ссылки для Telegram и WhatsApp
excel/                         Susanna_Birthday_Party_RSVP.xlsx — шаблон таблицы
tests/rsvp.test.ts             Модульные тесты логики анкеты (vitest)
scripts/e2e-rsvp.mjs           Сквозной тест в браузере
scripts/mock_flow.py           Локальная имитация потока Power Automate
docs/EXCEL_SETUP.md            Подключение Excel и доступ для Susánna
docs/TEST_REPORT.md            Что проверено
```

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # модульные тесты анкеты
npm run build      # сборка в dist/
```

Пока Excel не подключён, после отправки анкеты появится честное сообщение
«Анкета ещё не подключена к таблице ответов». Ложного «Спасибо» не будет.

## Публикация на Vercel

1. Загрузите проект в репозиторий GitHub (можно приватный).
2. На vercel.com нажмите **Add New → Project** и выберите репозиторий. Фреймворк *Vite*
   определится сам.
3. В **Environment Variables** добавьте переменные из `docs/EXCEL_SETUP.md`.
4. Нажмите **Deploy**. Получится ссылка вида `https://susanna-party.vercel.app`, имя можно
   поменять в Settings → Domains.

Гости открывают сайт без регистрации. Страница закрыта от поисковиков (`noindex`).

## Что можно поменять в `src/config.ts`

| Поле | Что это |
|---|---|
| `date.year` | Год. Сейчас `null`, поэтому год нигде не выводится |
| `schedule.items` | Время и подписи: 15:30 — Сбор гостей, 16:00 — Начало праздника |
| `venue.address`, `venue.mapUrl` | Адрес и ссылка на поиск в Яндекс Картах |
| `dressCode.swatches` | Цвета и их названия |
| `colophon.url` | Ссылка «Создать своё приглашение» |

После правок опубликуйте сайт заново (`git push`).
